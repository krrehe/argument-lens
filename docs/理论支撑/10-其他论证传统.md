# 十 · 其他论证传统

> 这一编回答：**西方非形式逻辑之外，别的传统怎么算「把话说住了」——本工具为什么不采用。**
>
> 它存在的理由只有一条：第九编 T9-08 写过「本工具只有一套规范（分析传统下的非形式逻辑与论辩理论），不按文化传统切换标准」。
> 一句自认局限的话，如果不写出另一套长什么样，读者就没法判断它到底差在哪——
> 那句话说到底只是检讨。这一编把另一套摆出来，一段一段对照：哪一层对得上，哪一层对不上。

## 为什么是这五家，不是「东方智慧」大杂烩

选入的门槛是三条，缺一条不收：

1. **有成体系的论证理论**，不是零散的格言。墨家有「故、理、类」三物，因明有宗因喻三支与因三相，都是可讲结构的。
2. **有可核查的原始文献**，能引到篇名。这一编六条里五条是 A 档，唯一一条 B 档（T10-04）是因为解读本身有分歧，不是因为没有原文。
3. **能与本工具做对照**——要么对得上某一层（值得写「它和我们一样分三层」），要么能指出一处明确的缺口（值得写「这一层我们没有」）。

按这三条，一大批东西被挡在外面：阴阳五行的类推、禅宗的机锋、诗话里的「意境」。
不是它们不重要，是它们不提供**可以拿去检查一段论证**的东西。
把它们收进来，这个库就会从「可质疑的主张集」变成「文化陈列」。

## 墨家：三物必具，然后辞足以生（T10-01 / T10-02）

《墨子·大取》：「夫辞以故生，以理长，以类行者也。三物必具，然后辞足以生。」

一个论断站得住，要有三样：**故**（理由）、**理**（所依的法则）、**类**（它属于哪一类、能推及哪些同类情形）。
这一条比图尔敏早了两千多年，而且分层不同：图尔敏分的是「依据 / 担保 / 支撑」，
墨家分的是「理由 / 法则 / 类推范围」——第三项图尔敏没有对应物。

对照本工具：

| 墨家 | 本工具 | 对得上吗 |
|---|---|---|
| 故（理由） | 前提、grounds | 对得上 |
| 理（法则） | 担保 warrant | 勉强对得上：warrant 是「凭什么这一步能推出」，理更宽，含「什么算成立」 |
| 类（类推范围） | 无 | **对不上**。类比专题只问相似点是否落在担保链上（T3-07），不问「凭什么算同一类」 |

第三行是这一编最实在的一条：**「类」这一层我们没有。**
它不是待办事项——要做它得先有一套「同类」的判据，而那一套在墨经里与伦理秩序缠在一起，
搬过来就不再是逻辑工具。所以照实写成缺口，不写进路线图。

《小取》另有三层：「以名举实，以辞抒意，以说出故。」
这一条**真能对上**，而且对得很整齐：

| 墨家 | 本工具 | 落点 |
|---|---|---|
| 名（概念） | 术语与定义专题 | `topics.ts` 的定义栏 |
| 辞（命题） | `conclusion` 字段 | 存「他要你信的那句」，不存主题 |
| 说（论证） | 前提 + `supports` 支撑链 | 结构图 |

不是所有比较都要以「我们不如人家」收尾。这一处两边都在分「概念／命题／理由」三件事，
分得一样，这就是可对照的地方。

## 三表法：它没有文本以外的世界（T10-03）

《墨子·非命上》给检验主张定了三条路：

- **上本之于古者圣王之事**——历史经验；
- **下原察百姓耳目之实**——当下见闻；
- **发以为刑政，观其中国家百姓人民之利**——实际效果。

三条全部指向文本之外。而本工具**只看文本内部**：前提、结论、担保、检查项。
三表法里没有一表是它能做的。

这不是谦虚，是能力边界。它没有文本以外的世界——不查史实、不做调查、不评估政策效果。
所以学术分析里那几处「待核」（`tracesOf` 抽出的年份引用、样本、百分比）只能指方向，
核不了内容。这一点写进了报告底部的边界栏，不是写在文档里等人发现。

顺带说清一件事：这条边界**不因接入联网检索就消失**。
查得到一篇论文的页码，不等于查得到它是否被后续研究推翻；
三表法里的第二表和第三表，本质上要求的是调查与试行，那是另一件事。

## 名家与荀子：名是为了辨实（T10-04 / T10-05）

「白马非马」流传下来时已经被当成诡辩的代名词，但它原本说的是：
「白马」与「马」两个名所指的范围不同，所指不是一回事。
这是关于**名的层次**的讨论，不是耍赖。

本工具在这一点上是空的：定义专题只查一件事——同一个词在前提与结论里含义变过没有（T3-12、T5-09）。
它不查外延与内涵分几层，也判不了「这算不算同一个概念」。
遇到白马式的论辩，它只能标出「这里在谈名实关系」，给不出判定。
原因是这类型争的胜负取决于你采用哪套名实理论，而本工具没有那套理论。

荀子那条则**对得上**。《正名》：「名定而实辨，道行而志通。」
定名是为了辨实，名混了事情就跟着乱。

这正是本工具命名纪律的古典对应：给谬误命名要过三道门槛（T5-04），
且命名不自动下调档位（T8-11）——名是为了辨实，不是为了显得高明。
反过来，硬套一个不相干的谬误名会让实更乱，所以宁可只写位置、不给名字。
这一条不是装饰性引用，它和那三道门槛说的是同一件事。

## 因明：为什么不做（T10-06）

陈那的因明论式是三支：

- **宗**（命题，如「声是无常」）
- **因**（理由，如「所作性故」）
- **喻**（同品喻 + 异品喻，如「如瓶，瓶是所作而无常；如虚空，虚空常住而非所作」）

它与三段论、图尔敏都不同：**喻这一支同时要求正例与反例**，而且正反例的成立本身要经得起追问（因三相）。

六副透镜里没有因明，也不打算加。理由是可操作性问题，不是文化偏好：
喻支要求举出同品与异品的实例，而本工具的输入只有一段文本——
看不出说话者愿意把哪些实例算作同类。这一支读不出来，硬做就是替对方编例子，
而那正是 `core.three-never` 第一条禁止的事（编造原文）。

代价写清楚：遇到汉传佛教论式，它会被套进图尔敏——宗≈claim、因≈grounds——
那是范畴错误，而错误会安静地通过：报告看起来结构完整，实际上漏掉了整个喻支。
所以这一条进了报告的边界栏，而不是留在文档里。

## 这一编刻意没收的

| 没收的 | 为什么不收 |
|---|---|
| 「东方思维重整体、西方重分析」这类对比 | 是文化断言，不是论证理论。无法拿去检查一段话 |
| 阴阳五行的类推体系 | 有结构，但其「类」的判据来自宇宙论，搬进论证分析会把宇宙论一起搬进来 |
| 禅宗机锋、诗话意境 | 明确反对「可被结构化的论证」这一前提。收进来等于取消这个工具的前提 |
| 印度正理派的十六谛义 | 与因明重叠而更繁；四十余项分类对本工具的粒度没有增量 |
| 「中国没有逻辑」与「中国逻辑自成体系」之争 | 这是史学争论，工具不选边。只采用文献里能读到结构的那几家 |

## 落到代码

| 主张 | 落在哪 | 是什么形态 |
|---|---|---|
| T10-01 | `topics.ts` 的类比栏 | **缺口**：「凭什么算同一类」这一问没有 |
| T10-02 | `core.reconstruct` 块 | 对得上：名/辞/说三层各有位置 |
| T10-03 | 边界栏（`limits.ts`） | 边界：没有文本以外的世界 |
| T10-04 | `topics.ts` 的定义栏 | **缺口**：只查一词多义，不查名的层次 |
| T10-05 | `copi` 的 rules | 对得上：命名三道门槛的古典对应 |
| T10-06 | 边界栏（`limits.ts`） | 边界：没有因明，汉传论式会被套进图尔敏 |

六条里三条是缺口、两条是边界、一条对得上。这个比例本身就是结论：
**这套工具与墨家的距离，比与图尔敏的距离远得多。** 写出来，比说「兼容多元传统」诚实。

## 一句话收束

「只有一套规范」这句话，写出来只是承认；把另一套摊开对照，才知道自己少了什么。
这一编六条里没有一条是要新增功能的——它们要的是让那个缺口有名字。

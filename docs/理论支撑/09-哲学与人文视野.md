# 九 · 哲学与人文视野

> 这一编回答：**论证之外还有哪些读文本的方式，本工具为什么不采用。**
>
> 与第八编不同，这一编的主调不是「它让工具做了什么」，而是**「它让工具不做什么」**。
> 一个字段若只用于「不做某件事」，它就不存在——所以这一编的多数主张落到的是删掉的能力，
> 而不是新增的能力。这正是它们值得写下来的原因：不写，读者会以为工具只是还没做。

## 为什么加这一编

前八编全部来自一条线索：分析传统下的论证理论——非形式逻辑、论辩理论、型式、谬误、
批判性思维。这条线索很有效，也很窄。它默认了三件事：

1. 文本的意义在字面内容里，可以被抽成前提与结论；
2. 评估的标准是认识论的（真不真、够不够），不是权力的、修辞的、历史的；
3. 有一个中立的读者位置可以站在那里评估。

人文科学的三个方向分别否认这三件事：修辞学否认 1（说服还有品格与情感两个来源），
权力与立场论否认 3（不存在无立场之眼），诠释学部分否认 1（理解带着前见，
意义不等于字面内容）。把这些写进库里，不是要让工具改成它们那样，
而是为了让「本工具只用一套规范」这句话有据可查——现在它有十二处依据。

## 修辞学：说服有三个来源，工具只评一个（T9-01 / T9-02）

亚里士多德的 ethos / pathos / logos 三分，与佩雷尔曼的普遍听众 / 特殊听众，
共同指向一件事：**论证好不好，与它能不能说服人，是两件事。**

本工具只评 logos。不评说话者品格，不评情绪诉求的效果。
`audienceKind` 唯一的用处是调可接受性的门槛高低——对手受众的门槛天然更高——
它不用来给情感诉求打分，因为工具不知道听众是谁。

**同一份文本的档位不因受众切换而改写。** 否则同一句话会有两个「站得住」，
而那等于没有判定。

## 诠释学：善意原则不是宽容（T9-03 / T9-04 / T9-12）

伽达默尔与戴维森给的是同一条理由的不同版本：理解不可能从零开始，
「把文本读成它最强的样子」不是宽容，而是理解得以发生的条件——
你若不假定对方大体在说一件讲得通的事，你就读不出他在说什么。

这条直接落到重构模式：取最强读法，把其他合理解读写进 `unknowns`，
明确禁止「挑一种读法、然后当它唯一」。后者是给对方塞一个更好打的版本。

韦伯的区分（说明因果 vs 理解意义）划出另一条线：**本工具做的是说明，不是理解。**
重构模式不声称「作者真正想说的是」——它给结构、给型式、给条件，不进入说话者的意义世界。

哈贝马斯的理想言说情境则从反面划界：论证这种言语行为的语用前提是
参与者不受强制、可以质疑、彼此真诚。前提不成立时，看上去的「论证」其实是别的东西
（宣传、命令、表演）。本工具**不检测这个**：强制与不真诚发生在言说情境里，不在文本里。
它只能看文本，所以它假定文本真诚，并且不输出任何关于动机的判断。

## 言语行为：一句话在做什么不等于它的字面内容（T9-05）

奥斯汀与塞尔的区分有个很实际的后果：**反驳必须落在被断言的命题上。**
「他说得难听」不是异议，因为它没有可被断言反驳的内容。
`objectionKey` 按字段与范围定位，就是为了把这类东西挡在外面——
它们看起来像异议，实际上是评价。

## 权力与立场：最难处理的两条（T9-06 / T9-07 / T9-08）

福柯与立场论（Harding、Haraway）说的都是：**什么算证据、谁有资格说话，
不是由逻辑决定的。** 这一类批评最有力的地方在于，它对评估工具本身也成立——
一个自动评估论证的工具，本身就是一个「谁有资格说话」的装置。

本工具的回应刻意很弱，写在三条 `decides` 里：

- 它问「专家与这个结论有利益关系吗」，但**不评估制度性权力**；
- 它**不声明自己的视角**，报告里不写「从某某立场看」——理由是这句声明既不可核，
  又会让人以为视角问题已经处理了；
- 它**只有一套规范**（分析传统下的非形式逻辑与论辩理论），不按文化传统切换标准。

第三条最关键：这三条都是「不做」，而「不做」在这个库里是合法落点。
**把局限写成已知限制，比写成「兼容多元传统」更诚实**——后者是一句无法兑现的话，
而前者至少能被反驳。

T9-07 的 `contested` 里留了正面批评：不声明视角就是默认站在 dominant 视角上。
这条批评成立。本工具承认它，仍选择沉默，理由写在那一条里。

## 与分析传统同源的三条（T9-09 / T9-10 / T9-11）

最后三条不是「外部视角」，是分析传统自己的边界：

- **是与应当**（休谟）：`PtaStatementType` 把 `value` 与 `fact` 分开计，
  不允许拿事实前提充当价值前提。缺口被填上时，必须能指出填进去的那一句是哪一句。
- **明希豪森三难**：检查不递归。前提只被要求「有没有独立支持、是否落在共同起点之内」，
  不要求它自身也被证明。工具停在第一步，不停在最后一步。
- **迪昂—蒯因整体论**：一条检查项没过，不把整篇判成 fails。
  一条支撑链断了只减去它自己那份支撑——这与削弱/击败之分同向，
  两者都反对「一点坏了全都坏了」。

## 这一编刻意没收的

- **文学批评与叙事学**（文本的文学性、叙事结构、隐喻网络）。与论证评估的接口太弱，
  硬接只会产出「这段有隐喻」这种既不可反驳也无用的话。
- **精神分析与症候阅读**（文本没说出的东西才是关键）。不可证伪，且与善意原则正面冲突：
  一个工具若被授权读出「作者真正想说的」，它就永远能找到它想找的东西。
- **后结构主义的文本观**（意义不确定、作者已死）。这一条与 T9-04 的善意原则不可调和：
  若意义彻底不确定，重构就没有「最强读法」可言。取舍写在 T9-04 里：本工具选择可核的那一边。

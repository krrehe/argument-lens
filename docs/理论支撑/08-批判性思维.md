# 八 · 批判性思维

> 这一编回答：**「会思考」由哪些能力与习惯构成，本工具代劳了哪几样。**
>
> 读法：先读「为什么加这一编」，再读条目。每条主张都写了 `decides`（它让本工具做了什么）；
> 指不出落点的主张不进库，这一编同样守这条规矩。

## 为什么加这一编

前七编是从**论证理论**那边长出来的：非形式逻辑、论辩理论、型式与谬误。它们回答的是
「一个论证好不好」。批判性思维传统回答的是另一个问题：**一个会思考的人具备什么**。

两个问题相邻，但不等同。一个论证可以结构完好而思考者糟糕（他只是运气好）；
一个人可以思考得很审慎而这次的论证就是有洞。把两者分开，才能说清本工具到底代劳了什么——
否则界面上写的「帮你批判性思考」，是一句既无法兑现也无法反驳的话。

这一编的写法因此与前七编不同：**它有一半篇幅在写本工具不做什么**。批判性思维的六项技能里，
本工具代劳三样、代劳半样、完全不代劳一样。把这个账算清楚，比多引几篇文献更有用。

## 六项技能与本工具的对照（T8-01 / T8-07）

Facione 的 Delphi 共识把批判性思维分成六项：解读、分析、评价、推论、说明、自我校准。
逐项对账：

| 技能 | 本工具 | 说明 |
| --- | --- | --- |
| 解读（interpretation） | 半样 | 切分是启发式，不是理解。它按段落与标点切，不按论证单元切 |
| 分析（analysis） | 代劳 | 六副透镜的检查项，逐关展开 |
| 评价（evaluation） | 代劳 | 档位与依据 |
| 推论（inference） | 暗做，不展示 | 模型从文本到字段的这一步，界面上看不见中间过程 |
| 说明（explanation） | 代劳 | 每关的依据栏 |
| 自我校准（self-regulation） | **不代劳** | 不回查自己的依据是否自洽，也不检查这次选的透镜对不对 |

最后一行是这个工具最难看的一行，但它必须写出来。一个工具若自称会自我校准，
读者就会停止校准它——那比不做更糟。这一条写进报告底部的边界区块，而不是留在这里。

## 技能与倾向是两件事（T8-02）

Facione 与 Ennis 都把「会不会」与「愿不愿意」分开。理由是经验性的：
逻辑课上得很好的人，照样只对自己的对手用逻辑。

本工具因此不输出任何关于人的评价——不评说话者是否开放、是否真诚，也不给用户打分。
它能做的是把文本摊开。倾向是人自己的事，工具插手只会产出「你看起来很理性」这种话，
而那正是批判性思维最不需要的东西。

## 思维标准里，只有两条单独立栏（T8-03 / T8-04）

Paul 与 Elder 给了思维的八个要素和九条标准。全都立栏很容易：九个字段，逐条打勾。
本工具只立了两个：

- **假设**落到 `unknowns`：补出来的隐含前提必须写出来，不许默认它读者自明。
- **广度与公平**落到 `steelman`：反驳必须给出对方最强的版本。

其余七条不单独成字段，理由写在 T8-04 的 `decides` 里：它们散在检查项中，
单独立栏会让一份报告看起来逐条都做了，实际上只是把同一句话抄九遍。
**一排全绿的勾不是严格，是排场。**

「观点」这一要素刻意不取：不要求模型声明它从哪个视角读。一句「我从 X 视角读」
既不可核，又会让人以为视角问题已经交代过了。这个选择的代价写在 T9-07。

## 批判不等于否定（T8-08）

批判性思维的一半是建设性的：把一个说法重构成它最好的样子，与拆穿它一样重要。
所以工具里有重构与提问两个模式，它们 `givesVerdict` 为 false、档位一律未定——
不是省事，是因为一旦先判了它坏，重构就会把最强的读法悄悄换成最弱的读法。

## 两处学界没有共识的地方（T8-12）

批判性思维能不能跨领域迁移，McPeck 与 Delphi 共识两派还在争。
本工具不按领域切换判定标准：六副透镜对所有文本同一套，专题分析只列出该领域该问的问题，
不改阈值。争议没解决的地方，工具不假装已经选边。

## 这一编刻意没收的

- **批判性思维教育学**（怎么教、怎么测评、Rubric 怎么写）。本工具不做教学，参见 `docs/通俗与可视化.md`。
- **批判性思维的测量**（CCTST、WGCTA 之类量表）。量表测的是人，本工具看的是文本。
- **情绪智力、创造力、元认知训练**。相邻但不同，混进来只会让这一编变成「好品质大全」。

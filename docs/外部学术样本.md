# 外部学术样本：三段真文本，和一份只算了一半的账

> 2026-11-09。上一轮交付写着「本机 103 份存档里带学术字面线索的是 0 份，所以『这一圈的词』在真实学术文本上长什么样完全没有证据」，并请使用者给 2–3 段自己专业里的真文本。使用者回「自己去网上随便找然后用」，于是有了这三段。
>
> **这份文档只写判据与结论。** 进度与阶段状态只在 `docs/路线图.md`——本项目踩过一次「把进度写进第二份文档，软件上线后它还写着没有动手」的坑。

## 一、为什么是「找三段」，以及它不等于什么

「这一圈的词」是 2026-11-09 做的一栏：词表由人给，本地只按字面数出现次数、落在哪几句、报告结论／前提文字里有没有。当时量过 40 段评测语料，15 段学术体裁里显式定义词命中 0 段，所以把「自动认术语」砍了；但那一栏**从没在一段真正的学术写作上跑过**——本机存档全是校园早读、带货文案这类文本。

这一轮补的是这一条：拿三段公开的、可核查出处的学术文本，用界面**同一个纯函数**跑一遍，看原文侧有没有可复算的信号。

它**不等于**三件更容易被读成的事：

- **不等于「你自己专业里的真文本」**。使用者让我随便找，我挑了三个互不相同的学科（哲学认识论 / 认知科学 / 计量经济学），但那是我的挑选，不是你所在那个圈。词表也不是那个圈里的人给的。
- **不等于真实使用证据，也不等于 P2 的输入**。本机 103 份存档里带学术字面线索的仍然是 0 份，没有第二个人用这一栏读过自己的文本。
- **不等于论文正文里的论证段落**。三段都是**期刊摘要**，是「本文做了什么」的元陈述。它能验专业词在学术写作里的字面分布，验不了论证结构，更验不了「这段论证站不站得住」。把摘要当论证文本就是造假。

## 二、三段逐字文本与出处

文本逐字抄自各自 `url` 所指的页面，抓取日 2026-11-09，标点按该页保留。**逐字依赖转录**：同一段字在不同站点标点会不同（汉斯 PDF 索引用半角逗号、期刊 HTML 页用全角；Bartik 那篇武大机构库用半角、国家哲社文献中心用全角），所以出处页本身就是口径的一部分，换一页抄，字面次数可能变。

### 1 · 哲学 / 认识论

- 《经验的边界：洛克“白板说”的认识论阐释与数字时代的认知困境》，郭育铷（天津外国语大学欧美文化哲学研究所）
- 《交叉科学快报》2026, 10(4): 891-897；2026-07-08 发布；DOI `10.12677/isl.2026.104106`
- 页面：<https://www.hanspub.org/journal/paperinformation?paperid=145729>（Hans Publishers 开放获取期刊，HTML 摘要页公开可见）
- 逐字核对：<https://pdf.hanspub.org/isl_1220599.pdf> 的检索索引（正文文字同、标点为半角）
- 该页关键词：约翰·洛克、白板说、经验主义、算法推荐、信息茧房、反省

> 约翰·洛克在近代经验主义哲学中提出的“白板说”，确立了人类知识起源于经验的核心命题。在其认识论体系中，经验包含“感觉”与“反省”两个基本维度：感觉为心灵提供来自外部世界的原始材料，反省则使心灵能够对自身认知活动进行内在的观察、整理与建构。数字时代的到来深刻改变了人类经验的生成机制，传统意义上主动、开放、多元的经验获取方式，正逐渐被算法推荐机制重塑为定向输出、同质化且被动接收的认知经验。在这一技术逻辑的支配下，个体的认知边界不断收缩，认知结构日益固化。以洛克的“白板说”为理论视角，通过阐释其经验主义认识论的内在结构，揭示算法时代经验异化、认知封闭与反省能力弱化的现实困境。研究表明，激活洛克所强调的反省精神、重建主动认知与开放经验，是突破数字认知困境、恢复心灵主体性的可能路径。

这次填的词表：`白板说`、`经验主义`、`反省`、`感觉`、`算法推荐`、`信息茧房`；对照词 `天赋观念`（洛克论敌那一侧的说法，这段摘要里没用）。

> 概念与定义是支撑人类思维与交流的核心基础范畴，传统研究长期存在概念—定义混同与理性独断两大根本缺陷，割裂理性与非理性认知的内在联系，无法合理解释虚构对象、数字虚拟对象等特殊概念范畴。本文以贯穿认知全流程的分辨—关联为基础性核心认知操作，提出理性与非理性是该操作在不同加工深度、不同神经通路下的协同表现形态，系统重构概念与定义理论体系。构建了“存在形态（实物/事件）×认知功能（分辨/关联）×认知层级（具象/抽象）”的三维八类概念分类体系，明确虚构与数字虚拟对象的分类归属，揭示概念从具象到抽象的演化机制；厘清定义的本质、二元结构及描述性—解释性类型划分，阐明概念与定义“本体—工具”的辩证关系。同时回应了双系统理论、语言与思维关系等主流学术争议。本研究填补了认知与逻辑等交叉领域的学术空白，为认知科学、人工智能等领域提供了统一的理论基础。

- 该页主题词：Bartik工具变量、份额权重、政策冲击、应用条件

> Bartik工具变量法在因果识别和政策评估等社会科学研究中的应用日益广泛，受到了越来越多的关注。然而，在大部分国内经济学经验研究中，该方法存在应用不规范甚至是误用的问题。本文结合理论计量的基本原理和前沿成果，尝试在一个统一的标准分析框架下，对Bartik工具变量法在因果识别中的应用进行系统性的归纳总结，以厘清其在实践应用中需要注意的一些问题。本文首先梳理了Bartik工具变量法的发展脉络，明确了Bartik工具变量的经典设定及其推广延伸。其次，阐述了Bartik工具变量法在因果识别中的基本策略，归纳分析了Bartik工具变量在实际构建过程中的一些常见问题，包括如何计算观测样本的份额权重、如何设定政策冲击的维度等。再次，详细分析了Bartik工具变量法在因果识别中的应用条件，并结合具体例子作出了解释说明。最后，在此基础上提出了一个详细的操作清单，并以贸易政策的影响研究为例，全面展示了该方法的应用实践。

**词表是谁挑的**：三段词表都由本次分析按出处页关键词与摘要正文挑，**不是领域专家给的、不是软件内置词库、不进产品**。每段另放一个「该圈常见但本文没出现」的对照词，用来确认「没出现」那一列真的会说话，而不是所有词都恰好命中、那一列永远空着。

## 三、怎么跑，跑出来是什么

```
npm run audit:field-samples
```

数据在 `scripts/fixtures/field-samples.ts`，算法在 `scripts/audit-field-samples.ts`。**口径不另写一份**：切句用界面那套 `sentenceBounds`（`@shared/reread`），数词用界面那套 `fieldTermsOf`（`@shared/field-terms`），所以这里量到的字面事实与「这一圈的词」栏里显示的是同一套算法。

命令逐段打印：出处、体裁、原文句数与字数、每个词出现几次 / 落在哪几句 / 首现在第几个字、哪些词一次没出现、有几个词跨 ≥2 句，末尾合计。**这些数字由命令当场算，不写进文档**——没有断言守着的数字一定会烂，实时数以命令输出为准。

命令自带硬断言自检，失败真实退出 1、不打印数字：构造样本（切出 3 句、命中词 2 次落第 1/3 句、对照词 0 次）、样本出处字段齐全、每段至少三个词按字面命中、对照词必须没出现、三段学科与出处互不相同、**本文档的三段引用块与数据文件逐字一致（含标点）**、以及**输出区不许读报告侧字段**。另有 9 组反证逐组点名改坏后真红（`scripts/.out/prove-field-samples.mjs`，临时目录不进 git），其中两组专门防「源码定位切错时守卫恒真或误伤自己」与「文档引号改一个字、字数却不变」这类不报错的错。

**验收（2026-11-10 更正）**：这里原先写「它不进 `verify`」，是照 `audit:provenance` 的先例抄的；但那条先例不进 verify 的理由是「依赖使用者自己的存档，换台机器没有就该明说量不了」，而这三段数据**固定在仓库里**，没有那个问题。现在同一套自检注册成 `check:field-samples` 进 `verify`（**38 项**，只打印一行结论），`audit:field-samples` 仍打印逐词账；两者共用一个入口、一份自检，不存在两份慢慢说成两件事。另有 4 组反证（`scripts/.out/prove-check-field-samples.mjs`）专门验「一行模式真的跑了自检，而不是只打印一句通过」。

## 四、量出来的结论：能说什么，不能说什么

**能说的**：原文侧**不是空面板**。三段真学术写作里，人给的词表按字面大多能命中，有落空的，也有跨句复现的；落句、首现、跨句分布都是可逐字复算的事实。这补上了上一轮欠的那半条证据——这一栏在真正的学术写作上会算出东西，而不是只有一段「取消早读」。

有两个值得单独看的字面事实，都说明「按字面算」不是一句口号：

- `信息茧房` 在洛克那篇的**关键词里**，摘要正文里一次都没出现。软件照实写「没出现」，不替它找同义、不替它翻关键词表。
- `Bartik工具变量` 是 `Bartik工具变量法` 的子串，于是次数把两种写法一起数了进去。这是设计里写明「互相包含的两个词各算各的、不做分词与归一」的结果，不是错字。

**不能说的**：**这三段**的报告侧四项（结论文字 / 前提文字 / 只在结论里 / 只落在没有条目落点的句子里）**没量**。它们只有原文，没有真模型报告；把空报告传给纯函数，它会写出「报告结论文字里没有这个词」——那是缺输入，不是事实。所以本脚本只采信 `count` / `firstAt` / `sentences` / `missing` 四个原文字段，并在输出里明写「未计」。

**但「报告侧量不了」这句话只对学术文本成立，别读成整个模块量不了**：本机 103 份存档本身就是真模型报告，这四个字段读的是报告的字与结构，跟文本属于哪个学科无关。`npm run audit:field-reports` 已在真报告上量过：结论文字、前提文字、只在结论里三项都会亮，绝大多数报告至少亮一项；只有「出现的句子都没有条目落点」几乎不亮，原因是判据要求该词**所有**落句都没被钉住，而高频词必然跨句——quiet 句本身并不少，词落在其中一句的也不少。那是判据语义带来的近乎空面板，不是功能坏了。它依赖本机存档，故不进 `verify`，实时数以命令输出为准。

因此这一轮**没有回答**「这一栏在**学术文本的真报告**里长什么样」，也没有回答「人填完这几个词是不是更会读自己那一行」。后者要人，不是要代码。

## 五、边界

1. 外部公开期刊摘要 ≠ 使用者自己专业里的真文本 ≠ 本机存档 ≠ 真实使用证据 ≠ P2 输入。本机存档里带学术字面线索的仍是 0 份。
2. 摘要是元陈述，不是论文正文里的论证段落；这里量的是专业词的字面分布，不是论证结构。
3. 词表由本次分析挑，不是领域专家给的、不是软件内置词库；每段带一个对照词。词表一换，账就换。
4. 逐字依赖转录，`url` 是口径的一部分；不同站点标点不同，换一页抄可能改变次数。互相包含的词各算各的，不做分词与归一。
5. **这三段的**报告侧四项未计（没有它们的真模型报告）。宁可明说量不了，也不让软件说「报告结论文字里没有这个词」这句假话。字段本身在本机真报告上已由 `audit:field-reports` 量过，但那不是学术文本。
6. **这不是主线进展**：本地独立判定点占比仍是 4.8%，`docs/怎么读一篇学术论证.md` 那条「不按学科切换标准」没有被推翻（标准始终不在软件里，在人手里），人看完有没有变化仍是零证据。把这三段写成「学术领域分析做出来了」就是文档比软件更自信。

## 六、怎么真的用起来

1. **在软件里用**：把上面任一段摘要复制进输入框，把该段的词表（逗号分隔）粘进「学术分析 → 这一圈的词」，点开就能看到本地按字面数的位置事实。词表只活在这一屏，刷新即清。要看到「报告结论／前提文字里有没有」那两列，得先跑完一次分析；本机已有的 103 份真报告能说明这些字段**会不会亮**（见 `audit:field-reports`），但要看到**这三段摘要**的报告侧，仍需一次真模型分析——本机无 Key、无本地模型、余额为空。
2. **换成自己的文本**：改 `scripts/fixtures/field-samples.ts` 里的 `text` 与 `words`，重跑 `npm run audit:field-samples`。文本和词表都是输入，不是结论；这一步不需要模型、不需要钱。
3. **这一轮没有把外部文本塞进产品**：示例六段没动（那是「每按一次看不同裁决路径」的文本，各有埋好的毛病），40 段评测语料没动（它有 `check:corpus` 的覆盖矩阵与人工标注，把一段强论证摘要塞成「埋了毛病」的样本是造假），界面与 `src/` 一个字没碰，因此**不需重打包**。
4. **下一步仍卡在同一道闸**：要判断「这一圈的词」值不值得往判定层走，需要一段你自己专业里的真文本（最好带一次真模型报告），或者余额到位跑跨模型评测。已经量掉的一格是「这些字段在真报告上是不是空面板」（不是，除了一项近乎空），仍缺的是**学术文本上那一次分析**和人的使用证据。这两件事都不是再写一块代码能替代的。

# 论证镜 Argument Lens

本地运行的论证分析工具。输入一段话，输出一份能逐条回原文核对的分析报告：结论是什么、哪一步没撑住、缺什么、可以怎么改。

它不判「你说得对不对」，只判「这一步论证有没有撑住」。每条判断都要指得出原文哪一句；指不出位置的名字与评价不进报告。**削弱 ≠ 反驳**。

## 六副透镜

| 透镜 | 判定单元 |
|---|---|
| 论证型式与批判性问题 | 一条 CQ（批判性问题） |
| 语用辩证十规则 | 四阶段 × 一条规则 |
| ARS 三标准 | 单个前提上的一个标准 |
| 型式周期表三特征 | 阶 × 轴 × 陈述类型 |
| 图尔敏布局 | 六要素之一 |
| 教科书名录对照 | 名录中的一个条目 |

一次分析用一副。换透镜不是换一个更准的答案，是换一双看不同地方的眼睛；**六副不合并、不折算总分**。

## 六种模式

| 模式 | 问的是 |
|---|---|
| 诊断 | 这段话站得住吗 |
| 深查 | 刚才那份诊断漏了什么 |
| 红队 | 对手会从哪儿打 |
| 查谬误 | 哪些位置对得上教材里的名字 |
| 重构 | 它的结构是什么 |
| 提问 | 我该问他什么 |

深查会跑两遍，费用与等待约为标准分析的两倍；发现是候选，不是判决。

## 报告里有什么

- 五行总结 + 论证逻辑链。
- 逐关检查：过了 / 没过 / 没答，各带依据。
- 判读：档位、限定、被驳倒的是论证还是结论。
- 反驳、修补、三种改法与代价。
- 命题账、枢纽前提、全流程账、覆盖账、自省。
- 原文逐句对照、论证地图、深查发现。

每条都带原文位置；报告末尾交代自己的边界，不替读者下最后判决。同一段跑过多副透镜时，多一栏「同一段，别的透镜看到什么」，只并列各自「最弱的一处」，不投票。

## 安装

Windows 10/11 x64。从 [Releases](https://github.com/krrehe/argument-lens/releases/latest) 下载，或使用本机 `dist/`：

- `ArgumentLens-Setup-1.0.0.exe` — 安装版，可改目录，建快捷方式
- `ArgumentLens-1.0.0-portable.exe` — 便携版，双击即用

首次启动会引导接入模型。Key 只存本机。

## 开发

需要 Node 20+。

```bash
npm install
npm run dev
npm run verify         # 全部静态检查（62 项）
npm run smoke          # 默认诊断跑道
SMOKE_MODE=deep npm run smoke
SMOKE_DENSITY=compact npm run smoke
npm run dist           # 安装包 + 便携版
```

技术栈：Electron + React + TypeScript + electron-vite。结构见 [AGENTS.md](AGENTS.md)。

## 边界

- 本地运行，报告与 Key 不出机器；不做云同步 / 账号。
- 只判论证这一步，不判结论真假。
- 六副透镜不合并，不加第七副。
- 模型有随机性；报告一样不等于判断对。

# 论证镜 — 项目长期记忆

本机 `D:\2026-10-31-09-22-55`。Electron + React + TS 的「论证镜」：拆开日常语言里的论证，
指出它站在哪、倒在哪、以及**哪一处其实站得住**。用户立场：**长期开发，代码只由 AI 写**，
他本人提供判断、钱、真实使用证据。

## 会话开场三步

1. 读 `AGENTS.md`（交接书）。2. 读 `docs/路线图.md`「一、现在的处境」与末尾「阶段状态」
   （**状态只写在那里**，别另起进度文档）。3. `npm run verify` 确认基线绿。
   **项数、条数以命令输出为准，别抄进文档。**

## 五条不可动摇

不给单一判定（诊断/红队/重构有档位，查谬误/提问/对照没有）；「此处合法」一栏不能删；
六副透镜不合并、不翻译，分歧本身是输出；失败必须可见（写盘失败抛到界面、空 catch 写
`@allow-silent:` 理由、断言不许静默跳过）；**文档不能比软件更自信**（没验过的别写成验过的，
没有断言守着的数字不写）。

## 操作规矩

- 新增断言**先红后绿**且**逐组点名预期那一行**；只看整体红不够。恒真断言比没有断言更糟：
  写在踩不到的样本上、`0===0`、空文本上找不到禁词、拿常量比常量、源码守卫被 import 那一行满足。
  验「顺序 / 去重 / 唯一」先造倒序 + 乱序 id 样本；验「覆盖 N 类」先问还有哪些轴没进计数。
- 碰了 `src/` 必须 `CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run dist` 重打包，并**逐个核 `dist/*.exe`
  时间戳**（safe-delete shim 会让 build 中断却 exit=0，只出一个 exe；离线 `-c.electronDist=...` 已固化）。
- 改了界面必须跑 `smoke`（`pack:check` 不覆盖它）；`build` 与 `smoke` 不能并发；
  多模式冒烟前 `rm -rf scripts/.out/smoke-userdata`。
- 只在特定时刻出现的屏、默认收起的小块，都留截图入口（预览页 `?xxx=1`、端到端 `SMOKE_*`）。
- 交付必说三件事：改了什么 / 验了什么 / **没验什么**。
- 本机 git 没配身份：`git -c user.name=workbuddy -c user.email=workbuddy@local commit`。
- `AGENTS.md` 上限 **200 split 行**（末尾换行也算一行），**第 50 轮起已顶满，加内容必须先压缩**；
  新增 `check:` 时 `check:docs` 会一次抓两处（AGENTS 漏写新关、README 项数没改）。
- 架构边界由 `check:arch` 守（shared 不碰 electron / node: / main、值 import 无环、常量一个家、
  整屏各住一个文件、组件冻结线）；拆组件后要把三屏 `SMOKE_*` 端到端都点开一次。

## 反复踩过的坑（按类合并）

**断言** — 只读断言量了被前面调用污染过的样本（用全新样本 + 快照）；判据脚本失败与判据失效
长得一样（npm shim、CRLF 跨行替换串不命中、脚本抛 TypeError）→ 出现「全部没命中」先怀疑脚本；
分离的词表互相吞词（「不一定」里的「一定」）→ 跨类判断共用一份占位记录；字面重合不归一化
→ 阈值两侧各造样本；`| tail` 量到的是 tail 的退出码 → `set -o pipefail`；两个布尔为真 ≠ 同一个东西，
子串断言会被句子里本来就有的词骗过 → 用整句正则；**断言里的期望值要按样本实算，别心算字数**；
同时改坏两处会让反证互相抵消 → 一次只破一处。

**构建 / 环境** — 本会话预设 `ELECTRON_RUN_AS_NODE=1`，跑真 Electron 要先 `unset` 再直调 exe；
建快捷方式不能用 WScript.Shell（COM 被挡）→ `shell.writeShortcutLink` 并回读；`verify` 并发，
怀疑被搞红先 `VERIFY_JOBS=1` 串行复现；`.mjs` 里不能有 TS 语法（typecheck 覆盖不到）；
heredoc 吃反斜杠第 N 次 → 用 Write 工具或 `chr(92)` 拼；**往 package.json scripts 末尾加项时
别把逗号复制到新行末**，JSON 尾逗号会让 `npm run` 整体崩（`EJSONPARSE`），看着像脚本坏了。

**界面 / 截图** — 视觉模型估版式会错、**裁图按目测坐标也会错**（第 48 轮连裁偏两次）→ 先量 bbox；
整页缩略图判不了小字与断行 → PIL 裁原图 + LANCZOS 放大；版式看图，**文字用 DOM 探针核**；
8.5px 汉字不是小是认不出；字数算得下不等于词断得对；格式化时间插进固定短语要连起来读
（「最近今天 18:12」）；探针抢跑（同一个 `executeJavaScript` 里点完就读）像「按钮点不动」
→ 分两次 + 等一拍；`check:css` 连 `var(--x, fallback)` 里的 fallback 也算变量缺定义；
`data-*` 写成布尔属性时，要求带 `=` 的源码守卫不会命中；**Edit 时用大段 old_string 替换，
写完立刻读回确认没有把函数体吃掉**。

**数据 / 措辞** — 「兼容某格式」不是声明出来的，是对方解析器读得进去（Argdown 用 `@argdown/core`、
`.prg` 用 msgpack/zip 裁判与对方 CLI；zip 小端 / msgpack 大端）；数字恰好相同会掩盖单位错，
每个数都要带单位并让端到端逐字核；「还没填」不等于「填错了」；判据自己错了时输出看起来和代码
错了一样（按 `result`/`landed` 数都报 0，实际字段是 `answer`/`confidence`）；缺口分两种：
样本太少、和一整个维度从没被覆盖过；`rewriteJsonl` 会吃掉坏行 → 删除用 `rewriteJsonlRaw`；
写死四项的清零说明在「全不适用」样本上说假话 → 措辞不实比排版错难发现，要单独配样本；
LCS 切出的片段可能是半句话（「错的」→「错误决定」只剩「误决定」），是逐字可复算的切法，
不是错字，但要写进已知限制；**存档是扁平的**（`raw` 与报告正文同在顶层），拿
`d.diagnosis || d` 当「只有正文」会让「旧口径」与「更严口径」输出一模一样，看着完全正常
→ 两种口径数字相同先怀疑脚本，给脚本配一条构造样本自检。
